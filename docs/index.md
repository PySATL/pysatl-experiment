# PySATL Experiment

PySATL is a free and open source statistics library written in Python, designed to support all major researcher demands for statistical experiments.

## Quick-Start

Follow the 4-step experimental workflow in `experiment_example/Quick-Start_Template.md`.

## Available Experiment Types

- **critical_value** - Calculate critical values for statistical tests
- **power** - Evaluate statistical power of tests
- **time_complexity** - Measure performance and time complexity
- **generation_only** - Generate samples without statistical evaluation
